# upkeep-releases

Public release hosting for [Upkeep](https://github.com/jeffevertse/Upkeep) — a
private repo. This repo exists only to serve `appcast.xml` and signed `.dmg`
releases over GitHub Pages, since Sparkle needs a publicly reachable feed URL.

No source code lives here. Published by `scripts/release-self-update.sh` in the
Upkeep repo.

- Appcast: https://jeffevertse.github.io/upkeep-releases/appcast.xml
